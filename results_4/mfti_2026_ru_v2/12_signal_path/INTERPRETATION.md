# Интерпретация результатов анализа сигнальных путей (Signal Path Analysis)

## 1. Что такое сигнальный путь?

Сигнальный путь — это **последовательность остатков**, которая передаёт информацию от лиганда (глутамат, лигур) к трансмембранному домену (TMD). Путь вычисляется через:

1. **DCCM (Dynamical Cross-Correlation Matrix)** — корреляции движения между остатками
2. **Физический контакт (10 Å)** — остатки должны быть близко друг к другу в пространстве
3. **Алгоритм Dijkstra** — поиск пути с минимальной стоимостью (максимальной корреляцией)

---

## 2. Значение B-факторов (Beta-факторы) в PDB файле

В файле `mglu3_paths_colored.pdb` используется следующая кодировка B-факторов:

| B-фактор | Значение | Смысл | Цвет в VMD |
|----------|----------|-------|-----------|
| **0.00** | Фон | Остатки не в пути | серый |
| **1.0** | Только в A | Только в пути с арестином + кассивирующая мутация | синий |
| **2.0** | Только в C | Только в пути БЕЗ арестина | красный |
| **3.0** | Universal hub | **Во ВСЕХ путях** (универсальный хаб) | белый |
| **5.0** | Source/Target | Начало (901) и конец (724) пути | чёрный |

### Как это использовать в VMD?

```tcl
# 1. Откройте PDB файл
mol new mglu3_paths_colored.pdb

# 2. Установите отображение по Beta
mol modcolor 0 0 Beta

# 3. Выберите представление (cartoon лучше всего для видимости пути)
mol modstyle 0 0 Cartoon

# 4. (Опционально) Раскрасьте по Beta с кастомной палитрой
set sel [atomselect 0 "all"]
$sel set beta [linsert [$sel get beta] 0]
```

## 3. Интерпретация результатов для каждой системы

### Система A (mGlu3 + Arrestin + мутация)

- **Длина**: 16 остатков

- **Характер**: ВЫСОКАЯ стоимость → слабая корреляция между соседями → путь "расфокусирован"

### Система B (mGlu3 + Arrestin, другая нумерация)

- **Стоимость пути**: 0.5355
- **Характер**: САМАЯ ВЫСОКАЯ стоимость → самый "слабый" путь → наибольшая подвижность

### Система C (mGlu3 ОДИН, БЕЗ Arrestin)
- **Путь**: 901 → 301 → 300 → 299 → 297 → 296 → 271 → 507 → 508 → 509 → 530 → 532 → 534 → 537 → 724
- **Длина**: 15 остатков
- **Стоимость пути**: 0.5173
- **Характер**: САМАЯ НИЗКАЯ стоимость → самая сильная корреляция → путь "сфокусирован"

## 4. Ключевые выводы

### ✅ Universal Hubs (универсальные хабы) — остатки с β=3.0

Эти **5 остатков** присутствуют во ВСЕХ трёх путях:
- **299** — ключевой узел в центре пути
- **300** — плотно связан с 299
- **509** — нижний центр внутреннего домена
- **532** — конвергентная точка
- **537** — финальный "мост" перед TMD

**Интерпретация**: Это **"позвоночник" аллостерического сигнала** — остатки, которые критичны для передачи информации независимо от наличия арестина + мутации.

### 🔵 Остатки только в A (β=1.0)

- 298, 510, 531, 533, 535
- **Интерпретация**: арестин + мутация ДОБАВЛЯЮТ альтернативные маршруты через эти остатки. Это компенсаторные пути, которые помогают стабилизировать сигнал при изменении нативной конформации.

### 🔴 Остатки только в C (β=2.0)

- 296, 301, 530, 534
- **Интерпретация**: БЕЗ арестина система использует ДВА БЕЗ ЭТИХ точек. Арестин либо блокирует эти маршруты, либо отвлекает сигнал в другую сторону.

## 5. Биологическая интерпретация

### Стоимость пути и эффективность сигнала

```
Стоимость ↓ = сильнее корреляции = эффективнее передача
Стоимость ↑ = слабее корреляции = "шумнее" передача
```

| Система | Стоимость | Интерпретация |
|---------|-----------|---------------|
| **C** (БЕЗ arrestin) | **0.5173** ⭐ | Самый чистый, эффективный сигнал |
| **A** (с arrestin) | 0.5292 | +2.3% стоимости — арестин слегка "беспокоит" путь |
| **B** (другая topology) | 0.5355 | +3.4% стоимости — система B менее стабильна |

### Гипотеза об арестине

**Арестин ОСЛАБЛЯЕТ, но НЕ ПЕРЕКРЫВАЕТ сигнала:**

1. ✅ Путь сохраняется (same universal hubs)
2. ✅ Арестин добавляет ДОПОЛНИТЕЛЬНЫЕ маршруты через 298, 510, 531, 533, 535
3. ❌ Но общая стоимость растёт на 2.3% → движение менее когерентно
4. 💡 **Вывод**: Арестин выступает как **модулятор**, не адаптер — он не перенаправляет сигнал, а добавляет "шум" через альтернативные каналы

## 6. Как использовать эти результаты дальше?

### Для экспериментов:

1. **Мутируйте universal hubs** (299, 300, 509, 532, 537) — они должны быть критичны
2. **Проверьте остатки A** (298, 510, 531, 533, 535) — они должны быть важны только в присутствии арестина
3. **Проверьте остатки C** (296, 301, 530, 534) — они должны быть компенсаторными БЕЗ арестина

### Для симуляций:

1. **Проверьте корреляции** в каждой системе вдоль пути
2. **Анализируйте динамику** вокруг universal hubs
3. **Вычислите время** прохождения сигнала через каждый хаб (residence time)

### Для структурной биологии:

1. **Загрузите PDB** в VMD и раскрасьте по Beta
2. **Проверьте расстояния** между соседними остатками в пути
3. **Визуализируйте** на молекулярной поверхности, где лежат эти остатки

## 8. Быстрая справка: B-факторы в VMD

```tcl

mol new mglu3_paths_colored.pdb

# Если нужна кастомная палитра (синий-белый-красный):
mol modstyle 0 0 Cartoon
set sel [atomselect 0 "beta > 0"]
$sel set radius 1.5  ; увеличить размер видимости

# Для VDW сферизма
mol modstyle 0 0 VDW
```
